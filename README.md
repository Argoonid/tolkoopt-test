# Тестовое задание — ТОЛЬКООПТ (Python)

Исправленная функция `recommend_price` в `starter.py` и набор автоматических тестов в `test_starter.py`.

## Требования

- Python 3.10+ (используется только стандартная библиотека)

## Запуск

Пример из задания:

```bash
python starter.py
```

Автоматические тесты:

```bash
python -m unittest discover -v
```
